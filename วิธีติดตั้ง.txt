ชำดี POS v7.3 — วิธีเอาขึ้นเว็บให้ใช้งานจริง (ฟรี)
==================================================
ทำไมต้องขึ้นเว็บ: กล้องสแกน เครื่องพิมพ์บลูทูธ จอลูกค้า และระบบสมาชิก
ทำงานได้เฉพาะเมื่อเปิดแอปผ่านลิงก์ https (เปิดจากไฟล์ในเครื่องจะถูกเบราว์เซอร์บล็อก)

ขั้นที่ 1  เอาโฟลเดอร์นี้ขึ้นเว็บ (เลือกวิธีเดียว)
  ก) Netlify (ง่ายที่สุด)
     1. เข้า app.netlify.com → สมัคร/ล็อกอินฟรีด้วย Google หรือ GitHub
     2. เลือก Add new site / Add new project → Deploy manually
     3. ลาก "ทั้งโฟลเดอร์" chamdee-pos ไปวาง → ได้ลิงก์ เช่น https://xxxx.netlify.app
     4. (ไม่บังคับ) ตั้งชื่อลิงก์ใหม่ เช่น cmshop-pos.netlify.app
     อัปเดตเวอร์ชันใหม่: แท็บ Deploys → ลากโฟลเดอร์ใหม่ไปวางทับ (ข้อมูลร้านในเครื่องไม่หาย)
  ข) GitHub Pages: สร้าง repository → อัปโหลดไฟล์ทั้งหมด → Settings › Pages → Deploy from branch

ขั้นที่ 2  เครื่องขาย (แนะนำ Android + Chrome)
  1. เปิดลิงก์ https ของร้าน → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
  2. ย้ายข้อมูลเดิม: เครื่อง/ลิงก์เก่า การตั้งค่า › สำรอง → ลิงก์ใหม่ การตั้งค่า › กู้คืน
     (ข้อมูลเก็บแยกตามลิงก์ เปิดลิงก์ใหม่ครั้งแรกจะเห็นข้อมูลตัวอย่าง)

ขั้นที่ 3  จอลูกค้า (Customer Display)
  - เครื่องเดียว/จอที่สอง: เมนู การเชื่อมต่อ › "เปิดจอลูกค้าในหน้าต่างใหม่"
  - แท็บเล็ตอีกเครื่อง: เปิด https://ลิงก์ร้าน/#display → ขึ้นรหัส 6 ตัว + QR
    → ที่เครื่องขาย การเชื่อมต่อ › จอลูกค้า › ใส่รหัส หรือกด "สแกน QR"
  - ทั้งสองเครื่องต้องต่ออินเทอร์เน็ต · จับคู่ครั้งเดียว ครั้งต่อไปเชื่อมเอง

ขั้นที่ 4  การสแกนสินค้า
  - กล้อง: หน้าขาย กดไอคอนกล้อง → อนุญาตกล้อง → เล็งบาร์โค้ด/QR สินค้าเข้าบิลต่อเนื่อง
  - เครื่องยิงบาร์โค้ดบลูทูธ: ตั้งค่ามือถือ › บลูทูธ › จับคู่ (โหมด HID/คีย์บอร์ด)
    ไม่ต้องเชื่อมในแอป เปิดหน้าขายแล้วยิงได้เลย ทดสอบที่ การเชื่อมต่อ › สแกนสินค้า
  - รหัสที่อ่านได้ต้องตรงกับช่อง "บาร์โค้ด / SKU" ของสินค้า

ขั้นที่ 5  เครื่องพิมพ์บลูทูธ: การตั้งค่า › เครื่องพิมพ์ › ค้นหาและเชื่อมต่อ → พิมพ์ทดสอบ

ขั้นที่ 6  ตัวเชื่อม Google (ซิงก์หลายเครื่อง + Lucky Points): ทำตามหน้า การเชื่อมต่อ (ใช้ไฟล์ ChamdeeCloud.gs)

ข้อจำกัด: iPhone/iPad ใช้เครื่องพิมพ์บลูทูธผ่านเว็บไม่ได้ (กล้อง จอลูกค้า ระบบสมาชิกใช้ได้)
